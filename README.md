# Sitio web estático de KAEMENTO

Este paquete contiene una versión independiente del sitio lista para publicar en la raíz de un hosting estático.

Archivos principales:
- index.html: estructura, contenido y metadatos.
- styles.css: diseño completo y adaptación móvil.
- script.js: menú, filtros de proyectos y formulario de WhatsApp.
- carpetas de imágenes, productos, proyectos, conceptos y catálogos PDF.

Publicación:
1. Descomprima el paquete.
2. Suba todo el contenido de esta carpeta a la carpeta pública o raíz del hosting.
3. Mantenga intacta la estructura de carpetas y las rutas.
4. Configure kaemento.com para apuntar al hosting.
